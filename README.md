# DMB.

Мрачный DMB-таймер для Android.

## Возможности
- Имя, дата призыва и дата дембеля при первом запуске.
- Процент службы обновляется каждую секунду.
- Большой счётчик оставшихся полных дней.
- Полоса прогресса.
- Новый оригинальный dark manga-style фон при каждом запуске приложения.
- Плавное появление главного экрана.
- Без рекламы, аккаунтов, виджетов и лишних экранов.
- Все данные хранятся локально.

## Сборка APK
1. Открой папку `DMB` в Android Studio.
2. Дождись синхронизации Gradle.
3. Выбери `Build > Build APK(s)`.
4. APK появится в `app/build/outputs/apk/debug/`.

Требования: Android Studio с JDK 17 и Android SDK 35.

Фоны в проекте оригинальные и созданы специально для интерфейса; они не являются копиями Pinterest-работ.
